## 2.1 追加：SPC 数值显示精度（2026-11-05）

用户反馈 SPC 数据出现 `0.0165472068000000037`、`1.355000` 这类过长数字，且“整数部分长 + 6 位小数”仍可能撑破表格。修复如下：

| 位置 | 原行为 | 修复后 |
|---|---|---|
| 子组数据明细 | `num(v, 6)` 的尾随零正则失效，`1.355` 显示成 `1.355000` | 统一的 `spcNum()`：最多 6 位小数、去掉无意义尾零 |
| 测量值较大时 | 整数部分可达 15 位后仍保留 6 位小数 | 小数位随整数位数自动减少，单值不超过约 14 个字符 |
| 控制图 tooltip / 规范限 | 直接插值 `stat.series`/`char.lsl`，暴露完整浮点 | 统一走 `spcNum()`，图表限值标签保留 4 位以保持紧凑 |
| 能力指标卡 | `X̄̄ / R̄ / σ / UCL` 直接插值服务端数值 | 统一走 `spcNum()` |
| 控制图导出（Word/Excel） | 子组表与计算结果写原始浮点，正文却是 2 位小数 | 服务端 `L.displayNumber()` 在 `spcCompute` 返回值和导出表格统一收敛 |
| 极小/极大值 | 极小值被四舍五入成 0 | `<1e-6` 或 `≥1e12` 改用科学计数法 |
| 布局 | `.g23` 右列 `1fr` 取 min-content，长数值撑破整行 | 改为 `minmax(0,1fr)`；KPI 数值允许换行 |

验证：向测试库导入 15 位小数数据后，明细显示 `10.0217 / 9.992401 / 10.0206`，tooltip 为 `10.011461`，图表限值为 `UCL 10.0417 / CL 10.011 / LCL 9.9802`；页面无横向溢出。`tests/spc-msa-calc.js` 新增显示精度断言，`tests/spc-subgroup-ui.js` 新增禁止裸插浮点的静态断言。

### 缺陷修复：非默认项目的图纸/包装图片无法显示（2026-11-05）

- 现象：在第二个项目（如 `SIM-APQP-20261102-01`）上传 PDF / PNG 图纸后，页面提示上传成功，但封面与缩略图空白。
- 原因：附件列表返回的 `url` / `download_url` 只有 `/api/attachments/:id/file`，**没有 `?p=<项目>`**；`<img src>`、`<embed src>`、`<a download>` 不经过前端 `api()`，服务端于是按默认项目（第一个项目）解析，返回 404“附件不存在或不属于当前项目”。
- 修复：`attachmentRows()` 生成 URL 时带上 `p=CUR`；上传后任何位置直接使用该 URL 都能命中当前项目。
- 兜底：图片 404/410 时不再显示破图标，封面提示“图纸预览加载失败…请重新上传”，缩略图显示“加载失败”徽标。
- 实测（浏览器，第二个项目）：PNG 封面 `naturalWidth=900`、PDF 以内嵌阅读器渲染出页面、包装图册缩略图 `naturalWidth=600`；把文件改名制造 410 后两处兜底提示均出现。
- 回归：`tests/attachment-api.js` 增加 4 项（URL 必须带 `?p=`、直连 URL 200、旧式无参 URL 404），`tests/p2-ui-and-data.js` 增加 5 项静态断言。
