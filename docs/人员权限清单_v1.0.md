## 0. 本版根据你的答复所做的调整

| 你的意见 | 已调整内容 |
|---|---|
| 1. 企业管理部是采购部门 | 新增采购角色 `purchase`，由**企业管理部**承担：生产物料、非生产物料（设备、模具工装、备品备件）、供应商、外包方管理 |
| 2. 领导者支持改由总工、总经理、管理者代表签署 | P1-14 / P3-10 / P4-08 的编制权从「厂长」改为 `chief` / `gm` / `mgmt_rep`；删除「厂长」映射 |
| 3. 生产设备、测量设备、工装管理归企业管理部 | P2-10、A-04 的编制权归 `purchase` |
| 4. 基础设施（水、电、气）归安全环保部 | 新增「设施与环境」授权（第 4、5 节） |
| **5. 内审由质量管理部牵头** | `auditor` 角色归属**质量管理部 · 内审组**；企业管理部不再承担内审 |
| **6. 设备台账、计量、评定归企业管理部** | 检具 / 量具台账、校准计划与记录、测量能力评定由 `purchase` 主责维护；MSA 研究方案与判定仍由质量部主导（第 5 节） |

| 角色粒度 14 个可以 | 因新增采购、副总按板块拆分，实际为 **18 个角色**（第 2 节） |
| 质量部不要全部代编权 | 质量部只编质量类交付物；缺人由 admin 兜底 |
| 副总经理按分管板块给交付物批准权 | 4 位副总各设角色，仅批准本板块交付物（第 2、7 节） |
| 项目经理由科研一所担任 | P0-01 / P0-02 / P0-10 / P1-16 / P2-13 由 `design` 编制 |
| 账号先按部门-岗位建 | 首批建岗位账号，命名规则见第 9 节 |
| 项目范围按建议 | 管理层与审核员全局可见，其余按项目成员 |

## 1. 一句话结论

把现有 4 个角色扩展为 **18 个角色**，按“**项目范围 → 模块动作 → 交付物归属**”三层授权；企业管理部承担**采购、设备工装、计量与评定**职能，安全环保部承担**设施与环境（温湿度 / 洁净度 / 水电气 / 纯水）**职能，内审由质量管理部牵头，领导支持类交付物上收至总工 / 总经理 / 管理者代表。

## 3. 权限模型

### 3.1 三个维度

**① 能看哪些项目（项目范围）**

| 范围 | 角色 |
|---|---|
| 全部项目 | admin、gm、chief、mgmt_rep、4 位副总、auditor |
| 仅参与的项目 | quality、engineer、design、production、inspector、purchase、business、std、staff |

- 项目未配置成员时保持现有兼容模式（所有账号可见）；一旦配置成员，只有成员 + 上述全局角色可访问。
- 全局角色看所有项目但不改数据（admin 除外）；副总只能批准本板块交付物。

**② 能用哪些模块（模块 × 动作）**

| 动作 | 含义 |
|---|---|
| 查 | 只读：查看列表、详情、图表，下载受控文件 |
| 编 | 新建、编辑、保存、提交、导入、录入数据 |
| 批 | 批准、审核、退回、发布、作废、冻结等**受控结论** |
| 管 | 配置关系 / 成员 / 字典 / 账号 / 备份等管理动作 |

**③ 能编哪些交付物（交付物归属）**

直接沿用交付物目录里已有的 `owner` 字段，映射到角色（第 6 节）。

### 3.2 不随角色变化的硬规则

| 规则 | 说明 |
|---|---|
| 不得自编自批 | 批准人不能是编制 / 提交人（现有 `assertNotSelfApproval`） |
| 受控后锁定 | 待审核 / 已批准 / 已完成的交付物不能直接编辑或增删附件，须先“发起修订” |
| 批准人取会话 | 请求体里的批准人一律被登录身份覆盖，不能伪造 |
| 只读角色 | staff / auditor 的所有写接口返回 403（设施管理账号除外，仅限环境与设施类内容） |
| 审计留痕 | 所有上传、作废、批准、权限变更写 `audit_log` |

**行为要点**
- 所有账号都能查看全部页面；写操作按岗位授权，越权返回 403 并说明缺少哪项权限。
- 交付物按目录归属：设计只编设计类、工艺只编工艺类，管理员兜底；非归属岗位在页面直接看不到保存/提交按钮。
- 副总只能批准本板块交付物；总工 / 管理者代表 / 总经理 / 质量不受板块限制。
- 停用账号立即失效其会话；不能停用自己；系统至少保留一个启用管理员。
- 安全环保部的 `facility01` 通过 `flags=facility` 获得「环境与设施」编制权，不因此获得其他写权限。
