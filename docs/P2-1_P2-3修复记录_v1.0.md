## 2. 设计

### 2.1 Q-01 常数边界

- `XBAR-R` / `XBAR-S` 的子组数必须为 2–10 的整数，否则抛出“子组大小必须为 2–10…不支持自动回退控制图常数”。
- 通过校验后直接使用 `A2/A3/B3/B4/D2/D3/D4/C4` 表值，删除所有 `|| 1.023` 之类静默回退。
- `controlMethod` 文案同样使用真实表值。

### 2.2 Q-02 R/S 子图

- 极差/标准差逐点用索引判断：
  - `value >= UCL - 1e-9` → 超出上限；
  - `lcl > 0 && value <= LCL + 1e-9` → 低于下限（R 的 D3=0、S 的 B3=0 时跳过下限）。
- 删除 `indexOf` 反查，重复极差不会都指向第一行。
- 零极差时上下限为 0，不产生“每点超限”噪声。

### 2.3 Q-03 零变差

- `sigmaWithin = 0` 时 `cp/cpk = null`，`sigmaOverall = 0` 时 `ppk = null`。
- I-MR 同样处理。
- `runRules`：等于中心线的点 `side=0`，重置连续计数，不再组成“连续 7 点同侧”。
- 上下控制限重合（σ=0）时跳过控制限判定。

### 2.4 Q-05 边界语义

- 控制限判定改为闭区间，浮点容差 `1e-9`。
- 连续同侧只统计严格大于/小于中心线的点；`=CL` 重置。
- 连续 15 点 1σ 以内改为 `<= σ`；连续 8 点 1σ 以外改为 `>= σ`。

### 2.5 Q-06 P 图

- 每个点 `i` 用自己的 `σ_i = sqrt(p̄(1−p̄)/n_i)` 执行 8 条判异规则，并按该点控制限判定。
- 不再用最大样本量的单一 σ 计算区域规则。
- `controlMethod` 文案注明逐点 σ_i。

### 2.6 M-01 GR&R 常数

- `d2t`：2/3/4/5 次 → 1.128/1.693/2.059/2.481（K1 倒数）。
- `d2p`：2–10 件 → 1.414/1.912/2.239/2.481/2.672/2.830/2.963/3.078/3.179（K3 倒数）。
- 保留 `d2o`（K2 倒数）不变。

### 2.7 M-14 样本量提示

- `computeGRR` 返回 `warnings`：零件数 <10、评价人数 <2 时提示，不阻断。
- MSA 结果面板显示警告条。
