# 电阻器质量系统 v1.3.0：关联文件预览与编制辅助

> 应用版本：1.3.0  
> 报告编号：V2.5  
> 实施日期：2026-11-02  
> 修订类型：正式功能版本

## 1. 版本目标

本版本将交付物上下游配置从“字段自动映射优先”调整为“关联文件预览与手动复制优先”，服务于实际文件编制。

- 保留上下游交付物链条。
- 点击关联项打开右侧常驻预览面板。
- 当前交付物保持可见、可编辑。
- 预览内容支持字段、表格、整段和整份复制。
- 字段自动映射继续保留，但移入高级设置。

## 2. 交互结构

### 2.1 桌面端

- 当前交付物显示在左侧。
- 关联文件预览面板停靠在右侧，默认约 480 px。
- 预览面板打开后不遮挡当前交付物。
- 切换关联文件时，面板保持打开并更新内容。
- 关闭面板或切换当前交付物后，预览状态清空。

### 2.2 移动端

- 预览面板改为全屏抽屉。
- 当前交付物页面不被撑宽。
- 表格在预览面板内独立横向滚动。

## 3. 版本选择

表单交付物提供：

- 当前内容；
- 最新批准版本。

状态、版本、负责人和批准人始终显示。没有批准版本时不伪造版本按钮。

## 4. 内容预览

统一预览接口支持：

- APQP 表单与检查表；
- DFMEA / PFMEA；
- PFD；
- 控制计划；
- SPC；
- MSA；
- PPAP 18 项证据。

字段和表格使用同一种只读结构返回，避免前端为每个模块维护独立预览逻辑。

## 5. 复制能力

支持以下复制粒度：

1. 单字段复制；
2. 表格单元格复制；
3. 表格行复制；
4. 整表复制；
5. 本段复制；
6. 整份关联文件复制。

表格复制使用制表符分隔，可直接粘贴到 Word 或 Excel。

## 6. 字段映射调整

- 主界面不再突出“配置字段联动”。
- 字段自动映射收进“高级设置”。
- 既有映射、同步记录和冲突处理继续兼容。
- 日常编制流程不依赖字段映射。

## 7. 验收

- 关闭当前表单开关：通过。
- 切换当前交付物自动关闭预览：通过。
- 面板内切换关联文件保持常驻：通过。
- 表单、FMEA、PFD、CP、SPC、MSA、PPAP 统一预览：通过。
- 字段与多种表格复制：通过。
- 当前内容/批准版本切换：通过。
- 桌面停靠与移动全屏：通过。
- 跨项目隔离：通过。
- `npm test`：通过。

## 8. 边界

- 预览内容只读，不直接写入当前交付物。
- 复制到当前交付物由用户手工完成。
- 不自动把预览内容视为已核对或已批准。
- 复杂图形以结构化表格呈现，不复制画布坐标或视觉样式。
