# PPAP 18 项与 APQP 阶段关联初稿

> 版本：V0.1 初稿  
> 用途：请质量、工艺、设计和项目负责人确认适用性、责任角色和提交等级  
> 原则：系统只提供关联提示和证据入口，PPAP 要素是否适用及是否完成仍由责任人确认

---

## 1. 建议工作流

```text
顾客要求与设计记录
  → DFMEA / 特殊特性 / 工程变更
  → PFD / PFMEA
  → 试生产控制计划
  → MSA 计划与 MSA 完成
  → SPC 初始过程能力
  → 生产控制计划 / 有效生产运行
  → PPAP 18 项取证
  → 冻结基线
  → PSW 签批和客户提交
```

关键联动规则：

1. P3-08 MSA 计划从试生产 CP 中“纳入 SPC”的项目特性和测量设备自动生成。
2. MSA 研究必须使用计划中的同一特性和测量设备。
3. MSA 合格后由责任人点击“确认研究完成”，计划才关闭。
4. SPC 监控项的特性和测量设备与 P3-08 MSA 计划保持一致。
5. PPAP 第 7、8、11、16 项直接读取 CP、MSA、SPC 和检具状态。
6. PPAP 最终完成仍采用人工确认，防止“系统有数据但文件或客户要求不适用”被误判。

## 3. 系统当前自动状态口径

| 自动状态 | 当前判断 |
|---|---|
| 已就绪 | 系统能确认上游对象已达到发布/批准/完成状态 |
| 进行中 | 上游对象已存在，但尚未达到完成状态 |
| 待开始/待关联 | 上游对象尚未创建或只能人工关联 |
| PPAP 状态 | 仍由 PPAP 页面人工填写证据并标记完成 |

## 4. 需要确认的决策

1. MSA 判定为“条件接受”时，是否允许完成 P3-08 计划并进入 PPAP？
2. PPAP 第 11 项初始过程能力的目标是否按普通特性 `Cpk≥1.33`、特殊特性 `Cpk≥1.67`？
3. 第 7 项控制计划是否固定读取 SOP 控制计划，并要求“已批准 + 已生效”？
4. 第 8 项 MSA 是否要求该特性的 SPC 测量设备与 MSA 计划设备完全一致？
5. 第 3、13、15、17、18 项是否允许纯人工证据，还是必须上传文件并记录版本？
6. PPAP 提交等级 L1-L5 是否决定哪些要素必须完成？
7. 客户特殊要求是否按客户建立独立模板，并作为 PPAP 打包强制清单？

## 5. 系统证据工作台

PPAP 每一项现在通过独立页面处理：

```text
/#ppap/{要素号}
```

页面包含应准备证据清单、项目内自动取证结果、人工模板和证据确认。  
FMEA 会直接读取当前项目对应类型的已发布版本及失效分析行；PFD、CP、MSA、SPC、检具也会读取对应模块当前状态。  
PSW、AAR、CSR 清单等人工文件可通过 `PPAP-{要素号}` 绑定自定义模板，支持上传、在线填写和原 Word 版式导出。
