# 电阻器质量系统 V1.5 实施与验证报告

> 版本：V1.5  
> 实施日期：2026-10-31  
> 范围：FMEA 候选留存、特性产品族/系列、APQP 结构树、阶段二级菜单、PPAP 05 流程图

---

## 1. FMEA 功能与失效候选

### 1.1 功能候选

- AI 每次固定生成 3 个功能候选。
- 功能候选写入 `fmea_function`，关闭窗口、刷新页面和重新进入项目后仍然存在。
- 采用一个功能后，其余未采用候选继续保留。
- 再次点击功能生成时优先读取已有候选，不重复调用 AI。
- 只有明确点击“重新生成候选”才再次调用 AI。
- 外部 AI 不可用时使用本地规则生成 3 条可编辑候选，并同样落库。

### 1.2 失效分析

- 每条正式功能有独立的“失效分析”入口。
- 失效候选写入 `fmea_failure_cand`，并与结构节点 `node_id` 和功能 `func_id` 绑定。
- 已生成候选在关闭弹窗和刷新页面后仍能加载。
- “采用”后自动创建 FMEA 分析行，并挂载到当前结构节点及当前功能。
- PC、DC 或 O/D 未完成时允许先形成草稿行，后续在分析行编辑器中补全；提交审核仍按原规则校验。
- 已生成候选可手动删除，不再因未采用而自动消失。

## 2. 控制计划特性与产品系列

### 2.1 项目特性来源

- 新建空白项目不再自动把整个产品族特性字典灌入 `project_char`。
- PFMEA 使用产品特性或过程特性时，系统只将该特性引入当前项目。
- 控制计划默认分组只显示当前项目 PFMEA 已使用或当前行已关联的特性。
- 未使用过任何 PFMEA 特性时，默认分组不显示，并提示先到 PFMEA 关联。
- 项目特性参数继续与共享特性字典隔离。

### 2.2 产品族与产品系列

- 新增 `product_series` 表。
- `project` 新增 `series_id`。
- `char_master` 新增 `series_id`。
- 特性适用范围分为：
  - 产品族通用：同一产品族下全部系列可用。
  - 产品系列专用：只在指定系列项目中可见。
- 新建项目必须选择产品族和产品系列。
- 特性字典可直接维护适用范围，并从产品族/系列字典引入项目。

现有数据迁移结果：

| 项目 | 产品族 | 产品系列 |
|---|---|---|
| RJ 系列项目 | 金属膜固定电阻器 | RJ 系列 |
| RX 系列项目 | 绕线固定电阻器 | RX 系列 |

历史 `project_char` 记录未删除，控制计划默认下拉通过当前项目 PFMEA 使用记录进行过滤。

## 3. APQP 关联结构树

- 关联结构树不再只显示 10 个主链路节点。
- 新页面展示交付物接口返回的全部目录项。
- 按 Phase 0–5 分栏展示输入、输出、活动、检查表和系统模块。
- 核心数据链覆盖：

```text
VOC / CSR → 设计目标 → 特殊特性 → DFMEA → DVP&R
→ PFD → PFMEA → 试生产 CP → MSA → SPC → PPAP → 经验教训
```

- 增加变更管理、采购与供应商等横向协同要求。
- 全量关联明细保留每项的上游和下游引用。
- 点击交付物或系统模块可进入原编辑页或对应模块。

## 4. 阶段管理

- 左侧“阶段管理”一级菜单点击后进入项目进度总览。
- 一级页面显示交付物完成度、草稿数、推进中阶段和阶段进度。
- 左侧二级菜单展开 Phase 0–5。
- 每个阶段独立页面只显示当前阶段的输入、输出、活动、检查表和阶段工具。
- 阶段页面支持上一阶段、下一阶段、上传、新建和返回总览。
- 阶段页面使用 `#apqp/{phase}` 地址，可刷新和直接打开。

## 5. PPAP 05 过程流程图

- PPAP 第 05 项顶部增加横向工序方框图。
- 方框图显示工序号、工序名称、设备/类型和状态。
- 下方保留完整工序明细表。
- 同时展示两类关键标记：
  - PFD 工序类型为“特殊过程”。
  - PFMEA 或控制计划关联到 CC、SC、安全特性的工序。
- 特殊特性和 CharLink 关联产品特性均已合并到工序标记。
- 窄屏使用横向滚动，不压缩方块内容。

真实项目数据验证结果：

```text
工序数：20
特殊过程：2
含特殊特性关联的工序：3
```
