# 电阻器质量系统 v1.2.0：交付物关联工作台与受控修订

> 应用版本：1.2.0  
> 报告编号：V2.4  
> 实施日期：2026-11-02  
> 修订类型：正式功能版本

## 1. 版本目标

本版本将近期分散的交付物联动、质量工具穿透、MSA 来源修正和批准后修订统一为一个受控版本，重点解决以下问题：

1. 上下游关系和字段同步信息难以快速阅读。
2. 字段映射配置与同步结果使用两套不同的信息结构。
3. 已批准交付物缺少明确的二次编辑入口。
4. 单独模块之间的同步方向和来源边界不清晰。
5. 页面修改缺少版本级范围、兼容性和验收记录。

## 2. 交付物关联工作台

### 2.1 上下游关系

- 表单交付物和质量工具统一展示上游输入、下游去向和当前状态。
- 表单到表单关系支持字段映射；模块类关系只做追溯和导航。
- 无输入内容统一显示 `-`，不再输出内部字段名、ID 或原始 JSON。

### 2.2 字段映射配置

配置抽屉改为三步结构：

1. **上下游范围**：选择来源表、目标表和匹配关系。
2. **字段对应**：使用表格连续配置序号、上游字段、下游字段、关联度、双方当前值和操作。
3. **确认写入**：明确预填、正式同步和人工值保护规则。

字段映射规则：

- 第一组映射同时作为匹配键，不再重复选择匹配字段。
- 同一上游字段只能映射一个下游字段。
- 下拉框显示字段当前值样例。
- 按高、中、低关联度排序，可由用户覆盖。
- 当前上游未批准时允许草稿预填；正式同步仍以批准版本为准。

### 2.3 同步明细

同步明细从横向四列表格改为分层结构：

- 关系头和版本状态；
- 关联类型与业务说明；
- 字段级“原同步 / 当前 / 上游”对比；
- 处理动作和受控状态。

只读引用与字段同步分别展示，避免同一表格中混合不同业务含义。

## 3. 受控修订

### 3.1 交付物

待审核、已批准、已完成交付物进入锁定状态：

- 字段不可直接编辑；
- 已批准/已完成显示“发起修订”；
- 修订必须填写原因；
- 原批准版本继续保留，新内容进入草稿；
- 重新审批前，下游继续使用上一批准版本。

### 3.2 质量工具

- 已发布 FMEA 增加“发起修订”。
- 已批准/已冻结控制计划增加“发起修订”。
- PFD 继续使用“撤回发布”。
- SPC 继续使用“修订配置”。

## 4. 单模块同步修正

### 4.1 MSA 计划

- 已批准 P3-08 计划作为 MSA 计划的正式上游来源。
- 与控制计划中的适用测量系统合并生成计划。
- 检具名称即使无法匹配台账，也保留快照并标记“检具待关联”。
- 项目特性缺失时标记“特性待关联”。
- 未建立有效特性和检具关联时，不能直接开展研究。

### 4.2 同步方向

- 删除 MSA 研究结果反向覆盖 P3-08 的同步逻辑。
- P3-08 保持计划主来源；MSA 模块保存研究结果和状态。
- PPAP 的 MSA 就绪判断同时识别 P3-08 和控制计划来源。

## 5. 数据与兼容性

- 新增 `gauge_code_snapshot`、`gauge_name_snapshot` 字段，启动时自动迁移。
- 旧 MSA 计划、研究记录和历史快照保留。
- 原有表单字段映射继续兼容，旧配置中的重复字段在编辑时自动合并。
- 本版本不删除已批准版本，不自动批准或驳回任何业务记录。

## 6. 验收

- `npm test`：通过。
- 交付物 API 联动检查：155 项。
- MSA 计划单元测试：通过。
- 浏览器验证：
  - 已批准交付物字段全部锁定；
  - “发起修订”入口可见；
  - 同步明细卡片可展开；
  - 配置抽屉三步结构与字段卡片正常显示；
  - 桌面及窄屏无横向溢出；
  - 页面 JavaScript 错误为 0。

## 7. 已知边界

- 关联度属于字段语义建议，最终映射由用户确认。
- 未匹配的项目特性和检具不会自动创建主数据。
- 已批准下游遇到上游新版本时仍会生成待复核差异，不自动覆盖人工内容。
- 本版本未增加 CA 电子签名或外部 IDP 集成。
