## 1. SPC 控制限核算

### 1.1 实际核算结果

以 `RES-CHIP-2026-02 / 湿热后阻值漂移` 当前数据集为例：

| 项目 | 数值 |
|---|---:|
| 规格下限 LSL | -0.5000 |
| 规格上限 USL | 0.5000 |
| 子组均值中心 X̄̄ | 0.0000 |
| 平均极差 R̄ | 2.3790 |
| 子组大小 n | 5 |
| A2 | 0.577 |
| 控制上限 UCL | 1.3727 |
| 控制下限 LCL | -1.3727 |
| R̄ / 公差带 | 237.9% |
| Cpk | 0.16 |

### 1.2 结论

控制限计算本身没有使用规格限，它采用标准 Xbar-R 公式：

```text
CL = X̄̄
UCL = X̄̄ + A2 × R̄
LCL = X̄̄ - A2 × R̄
```

因此：

- 绿色 `LSL/USL` 是顾客或项目规格要求。
- 红色 `LCL/UCL` 是过程当前子组内变差推导出的控制限。
- 数据在规格限内，不代表过程能力合格。
- 当前 `R̄=2.379`，是 `1.0` 公差带的 `237.9%`，说明子组内变差远大于规格带宽；控制限因此被拉宽，而 `Cpk=0.16` 进一步说明过程能力不足。

### 1.3 页面改进

- 增加控制限公式和控制限数值。
- 增加 `R̄ / 公差` 指标。
- 增加“控制限不是规格限”的解释。
- 当 `R̄ > 公差带的 50%` 时显示数据诊断。
- 当过程中心超出规格限时显示高风险诊断。

## 2. MSA 模拟数据

### 2.1 生成逻辑

模拟数据不再使用固定 `10 ± 小波动`，而是读取：

- 项目特性的目标值、LSL、USL 和公差；
- 测量设备的量程、分辨力；
- 零件数、评价人数、试验次数；
- 用户选择的目标 `%GRR`。

系统生成零件间真实变差、评价人偏倚和重复测量误差，并反复试算，使实际 `%GRR` 接近目标值。

### 2.2 量具分辨力

- `gauge` 表新增 `resolution`。
- 检具维护页面可填写分辨力。
- 模拟结果会显示量具有效分辨力和“十等分建议值”。
- 当量具分辨力大于公差带的 `1/10` 时提示分辨力不足。

### 2.3 完成确认

- MSA 计算后研究状态为“已计算”。
- 只有综合判定为“接受”时显示“确认 MSA 研究完成”按钮。
- 完成时必须填写确认人。
- 完成后研究状态变为“已完成”，并回写 MSA 计划。

## 3. APQP MSA 计划联动

### 3.1 数据表

新增 `msa_plan_item`，保存：

- 项目特性；
- 测量设备；
- 研究类型；
- 零件数、评价人数、试验次数；
- 计划日期、责任人；
- 来源 CP/SPC；
- 研究状态和完成时间。

### 3.2 自动生成规则

1. CP 行勾选纳入 SPC 后，必须关联项目特性和测量设备。
2. 系统自动形成 P3-08 MSA 计划项。
3. 如果 SPC 已有监控项，以最新监控项的特性和测量设备为准。
4. MSA 研究选择计划后，特性和测量设备必须与计划一致。
5. MSA 合格并确认完成后，计划状态变为“已完成”。
6. P3-08 交付物表格自动同步计划行。

### 3.3 P3-08 表格

P3-08 MSA 计划表增加以下列：

```text
特性 | 检具编号 | 检具名称 | 研究类型 | 零件数×人数×次数 | 计划日期 | 责任人 | 状态
```
