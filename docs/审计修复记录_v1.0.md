## 刻意保留

- **数字格式化两处实现**（`lib/logic.js` 的 `displayNumber` 与 `public/app.js` 的 `spcNum`）：目前规则一致，合并需要改前后端数据契约，收益不抵风险。规则变更时必须同步修改两处。
- **`data/initial-credentials.txt`（旧文件）**：含 4 段历史口令，无法判断哪一段对应现有 `qms.db`，未删除。新的口令只写入 `initial-credentials.<库名>.txt`；若有人忘记口令，用管理员的「重置口令」即可。
- **MSA 页面的「台账与校准 / 研究设计」按钮分组**：权限已生效，视觉分组未做。

## 未覆盖

- 请求体 413、登录锁定、删除项目清附件、MSA 只读锁四条只有代码路径，没有自动化测试；其中前两条需要构造大请求与连续失败，后两条需要浏览器或项目删除夹具。
- `lib/infer.js`、`lib/tree.js`、`lib/structure.js` 未逐行审读；两个浏览器 e2e 需安装 Chrome，未运行。
