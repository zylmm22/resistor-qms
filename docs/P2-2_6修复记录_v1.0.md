## 2. 主要改动

### 2.1 P2-2 控制图

- `controlChart`：y 轴 5 条刻度；每个 `<circle>` 内嵌 `<title>`（含标签、值、判异规则）；规则判异点橙色描边、超限红色；x 轴优先显示批次/时间标签并抽稀；I-MR 的 MR 子图按 `x(i+1)` 对齐并补 tooltip。
- SPC 页面：判异清单截断提示；图例按图型（P/C/I-MR/Xbar）动态；Cpk 空值中性并说明原因；能力区 R̄/S̄/MR̄/p̄/c̄ 动态；子组数 <25 时提示“Cpk 仅供参考”。
- Q-13：`expectedValues`、`inputHint`、占位符统一按当前分析图型。

### 2.2 P2-4 交付物编辑

- A-04：`docEditorCleanup` 在 `go()`/`goApqpPhase()` 中清理自动保存定时器、移除快捷键，并在 dirty 时补保存；`saveDoc` 使用 JSON 快照；`docBack` 等待保存。
- A-09：`docPct` 表格按行计分、按单元格非空比例给分。
- A-10：`documentDisplayData(code, raw)` 统一页面/预览/导出/关联预览的数据装配。
- A-11：`patchTable` 支持新增行克隆与删除行移除（导出函数导出以便测试）。
- A-17：状态/变更原因控件禁用时不提交其值。

### 2.3 P2-5 模板与解析

- A-12：`parseXlsx` 识别数字格式中的日期并还原；返回 `warnings`（多工作表、行/列截断、日期还原数量）；`maxRow/maxCol` 改为包含式索引并修正 1-based/0-based 混用；上传结果卡片展示警告。
- A-13：模板页仅对 grid 显示“字段映射/按业务数据填充”；后端拒绝非 grid 映射与越界单元格；`/apply` 返回差异清单，覆盖已填内容需 `confirm_overwrite`；CP 按交付物对应阶段、MSA 按项目统计；修改 schema 后映射需重新批准。
- D-01：`addChar` 内自建来源列表，修复 `ReferenceError`。
- D-04：`POST /api/chars` 事务化，支持 `import_project` 一次完成“建字典 + 引入项目”；前端快速新增改用该接口。
- D-05：符号原文保留多标记，`is_special` 只在无符号时按显式/原值派生。

### 2.4 P2-6 界面一致性

- S-08：Gate 通过/驳回二次确认 + ≥4 字评审意见（服务端强制）；新增撤回接口与按钮，撤回后阶段按派生规则回退。
- S-09：项目切换清理文档/CP/SPC/阶段/模板/PPAP 选中态并回总览。
- S-10：角色只读展示登录身份，移除“尚未启用登录级越权拦截”提示。
- S-11：`setRouteHash` 普通导航 pushState；`popstate`/`hashchange` 统一分发且不重复入栈；未知哈希提示。
- S-12：PPAP 0/0 显示“未开始”，进度条按 0 处理。
- S-17/S-18：小屏卡片内横向滚动、吸顶表头、`:focus-visible`、减少动效媒体查询。
- C-08：删除控制计划行按服务端 `deleted` 提示“停用/删除”，页面显示已停用行数。
- C-12：控制计划列名明确“CP 要求”与“SPC 配置”。
- M-08：最近 %GRR KPI 颜色/文案取服务端 `judgment`。
- M-09：建立台账抽屉以参数直接渲染，去除 `setTimeout` 预填。
