## 1. MSA 模拟规则与容差

### 1.1 模拟步骤

1. 以项目特性目标值为中心，在 LSL/USL 范围内生成具有差异的零件真实值。
2. 根据选择的目标 `%GRR` 分配测量系统总变差。
3. 将测量系统变差拆分为评价人偏倚和重复测量误差。
4. 测量值 = 零件真实值 + 评价人偏倚 + 重复测量误差。
5. 按量具分辨力对读数取整。
6. 使用正式 GR&R 算法反复试算，使实际 `%GRR` 接近目标。

### 1.2 容差

- MSA 页面的“容差”默认等于项目特性的 `USL - LSL`。
- `%Tol = 6 × GRR ÷ 容差 × 100%`。
- 容差是产品允许变差范围，不是控制限，也不是过程实际变差。
- 修改项目特性的规范上下限后，下一次 MSA 研究的默认容差会同步变化。

### 1.3 判定

- 综合结果取 `%GRR` 与 `%Tol` 中较差者。
- `ndc ≥ 5` 才可判定为接受。
- 只有“接受”研究可以确认完成并关闭 MSA 计划。

## 2. PPAP 证据工作台

### 2.1 页面代替弹窗

每个 PPAP 要素现在有独立页面：

```text
#ppap/{要素号}
```

页面包括：

- 应准备证据清单；
- APQP 阶段、建议责任人和关联对象；
- 系统自动取证结果；
- 项目内文件/模块入口；
- 人工证据模板；
- 证据引用和完成确认。

### 2.2 自动取证

| PPAP 类型 | 自动取证来源 |
|---|---|
| DFMEA / PFMEA | 当前项目最新 FMEA 版本和失效分析行 |
| PFD | 当前项目有效工序及发布状态 |
| CP | SOP 控制计划及控制行 |
| MSA | P3-08 计划、研究结果和完成状态 |
| SPC | 已批准监控项、控制图、Cpk/Ppk 和数据批次 |
| 检具 | 检具台账、校准和 MSA 状态 |
| 项目阶段文件 | 项目交付物内容、状态和版本 |

### 2.3 人工模板

PSW、AAR、CSR 清单、标准样品等文件可复用项目阶段模板功能：

- 上传 XLSX/DOCX；
- 在线填写；
- 按原 Word 版式导出；
- 模板与 `PPAP-{要素号}` 关联；
- 在 PPAP 证据页直接打开。

### 2.4 引用式文件呈现与审批

- 工程图纸、材料规范、设计记录等项目阶段文件在 PPAP 页面直接只读渲染。
- 可直接引用渲染的要素，以引用文件作为主内容；原“应准备证据”压缩为页面底部的简短“取证要点”。
- 页面显示来源编号、版本、更新时间和批准状态。
- 页面不复制、不重建源文件；审批仍在原项目阶段文件执行。
- 若源文件尚未批准，PPAP 证据确认会被后端阻止。
- FMEA、PFD、CP、MSA、SPC 等模块数据直接读取当前项目状态，不再要求重复上传。
- 仅缺少正式项目载体或顾客专用格式的文件使用人工模板补充。

## 3. SPC 工作台

### 3.1 页面结构

- 左侧监控项目列表：图型、特性、工序、测量设备、判异状态。
- 顶部工具栏：当前监控、分析图型、测量设备、数据格式、采样频率和 Cpk 目标。
- 中部：控制图、测量值分布和能力指标。
- 右侧：项目特性规范、能力指标、控制限说明和判异明细。
- 下部：历史数据集、批次数据和 Excel 导入。

### 3.2 支持的控制图

| 图型 | 数据格式 | 用途 |
|---|---|---|
| Xbar-R | 每行 2–10 个测量值 | 计量型、子组均值和极差 |
| Xbar-S | 每行 2–10 个测量值 | 计量型、子组均值和标准差 |
| I-MR | 每行 1 个单值 | 单件测量、破坏性或低频测量 |
| P | 每行“不良数, 实际样本数” | 不良率监控 |
| C | 每行 1 个缺陷数 | 固定检验单元的缺陷数监控 |

### 3.3 分析切换

对于同一组计量型子组数据，可在 Xbar-R 和 Xbar-S 之间切换分析视角。  
I-MR、P、C 应在控制计划生成监控项时按数据类型选择，避免用错误的数据口径解释控制图。

### 3.4 控制计划同步

控制计划生成 SPC 监控时会同步：

- 项目特性；
- 测量设备；
- 控制图类型；
- 子组大小；
- 采样频率和单位；
- Cpk 目标；
- SPC 状态；
- 对应 MSA 计划。
