## 1. FMEA Master V6.0 特点梳理

对《FMEA Master软件系统介绍V6.0》66 页 PDF 进行梳理后，其核心特点包括：

1. 以 AIAG-VDA 七步法为主线：策划、结构、功能、失效、风险、优化、结果文件化。
2. 结构树是主交互入口，BOM、框图和结构树共享同一套结构数据。
3. 功能分析支持系统、子系统、零件、工序和过程工作要素的逐层分解。
4. 功能网与失效网支持自下而上和自上而下关联。
5. 功能/失效矩阵可以在矩阵与结构树之间同步操作。
6. 上级 FM 可作为下级 FE，下级 FM 可作为上级 FC，形成连续失效链。
7. 风险分析、AP 筛选和优化措施直接挂在结构树上。
8. 与产品特性库、功能库、失效库、措施库和知识库联动。
9. 自动生成 BOM、PFC、CP、CC/SC 清单、DVP 清单和 FMEA 报告。
10. 支持任务、团队、问题、变更、经验、项目复用和权限协同。

本次迁移重点是企业版 FMEA 工作台最核心的交互方式：

```text
结构树 → 当前节点 → 功能 → 失效链 → AP → 优化/文件状态
```

## 2. FMEA 结构树工作台

FMEA 页面默认进入三栏结构树工作台。

### 2.1 左栏：结构树

- 按父子层级显示 DFMEA/PFMEA 结构。
- 支持展开、收起、搜索和节点选择。
- 每个节点显示：
  - 正式功能数量；
  - 失效行数量；
  - 高 AP 数量；
  - 待处理功能候选数量。
- 可直接新增、改名和删除结构节点。
- PFMEA 可从 PFD 同步结构，DFMEA 可从示意图生成结构。

### 2.2 中栏：节点功能与失效链

- 显示当前节点路径、名称、工序说明。
- 按功能卡片组织失效链，而不是把所有内容混成一张长表。
- 每条功能显示：
  - 对应失效模式；
  - FE、S/O/D、AP；
  - 措施和处置状态入口。
- 支持针对当前功能新增失效分析。
- 显示未关联功能的失效行，便于补齐功能关系。
- 候选功能可直接进入功能管理和 AI 分析。

### 2.3 右栏：分析与风险

- 显示七步完整度：
  - 结构；
  - 功能；
  - 失效；
  - 风险；
  - 优化；
  - 文件发布。
- 显示当前节点 AP 分布。
- 显示当前节点关联的产品特性和过程特性。
- 显示整个 FMEA 的结构节点、功能、失效行和高 AP 数量。

### 2.4 工作表保留

原 FMEA 完整工作表继续保留，可通过“完整工作表”切换。表格能力没有删除，适合批量检查、打印和逐行编辑。

## 3. PFMEA “选择或新增特性”

产品特性和过程特性下拉菜单新增：

```text
＋ 新增当前产品系列产品特性
＋ 新增当前产品系列过程特性
```

使用流程：

1. 在 PFMEA 分析行中打开产品/过程特性下拉。
2. 没有所需特性时选择“新增”。
3. 输入大白话描述。
4. 可点击“AI 标准化”生成名称、描述、单位、目标值和公差。
5. 保存后：
   - 写入特性字典 `char_master`；
   - 自动引入当前项目 `project_char`；
   - 自动回选到当前 PFMEA 关联下拉。

新增特性默认绑定当前项目的产品族和产品系列，不会混入其他系列。

## 4. 特性字典 AI 标准化

### 4.1 输入

用户可以输入类似：

```text
划槽深度目标 21 微米，上下允许偏差 3 微米，太浅掰不断，太深伤基片。
```

### 4.2 输出

系统生成：

```text
名称：切槽深度
描述：说明对象和可测量要求
单位：μm
目标值：21
下限：18
上限：24
公差：21±3 μm
```

名称规则：

- 使用简单名词短语。
- 不把“控制、确保、提高、防止”等动作写成特性名称。
- 名称不包含具体数值。
- 数值进入目标值、上下限和公差字段。

### 4.3 保存与同步

- 特性字典增加“简明描述”列。
- AI 结果先填入表单，必须人工复核后保存。
- 保存后可在特性字典、PFMEA、控制计划之间共享。

## 5. 验证结果

### 5.1 自动化测试

执行：

```text
npm test
```

结果：`Smoke tests passed`

新增覆盖：

- 大白话特性描述标准化。
- 中文单位“微米”转换为 `μm`。
- 目标值和 ± 公差提取。
- 特性简明描述写入主数据并同步到项目特性。
- 手工新增 FMEA 结构节点。

### 5.2 浏览器验证

- FMEA 默认显示三栏结构树工作台。
- 当前真实项目显示 22 个 PFMEA 结构节点。
- 结构树功能、失效和 AP 标签正常。
- 节点功能卡片和失效链正常联动。
- 完整工作表可切换并返回结构树。
- PFMEA 新增特性后自动回选。
- 特性字典可生成“切槽深度”“耐电压”等标准名称。
- 页面未捕获 JavaScript 错误。

### 5.3 AI 连通性

当前保存的 DeepSeek Key 仍返回 HTTP 401，因此：

- AI 特性标准化接口已实现；
- AI 不可用时的本地名称/数值提取已验证；
- 外部大模型标准化效果需更新有效 Key 后再做真实模型验收。

## 6. 尚未迁移的企业级能力

本次迁移的是 FMEA 核心分析交互。以下 FMEA Master 企业版能力仍属于后续扩展：

- BOM、框图和结构树的双向实时同步。
- 独立功能网、失效网和功能/失效矩阵。
- DFMEA 与 PFMEA 的跨项目失效传播。
- FMEA-MSR 独立分析。
- 企业知识库、措施库和项目模板复用。
- 在线团队任务、角色权限和多人协同编辑。
- PLM/QMS/MES 集成。

这些能力不会影响当前结构树、功能、失效和风险主流程的使用。
