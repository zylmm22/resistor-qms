## 2. 主要改动

### 2.1 FMEA

- `POST /api/fmea/row`：
  - S 一致性校验增加 `row_id<>?`（F-01）。
  - 编辑既有行且文本变化时重命名当前节点并审计（F-08）。
  - 返回 `downgraded/message`，发布后编辑提示回草稿（F-09）。
- `GET /api/fmea` 返回 `apMatrix`；前端 `AP_MATRIX` 改为查表（F-02）。
- `lib/db.js`：`bandLookup`、`healApMatrix`、种子 `INSERT OR IGNORE`（F-03）。

### 2.2 MSA

- `PATCH /api/msa/plans/:id` 支持 `status` 在计划/研究中之间迁移，退回需原因（M-03）。
- 种子 `msa_study` 写入 `char_id`，seed 后回填项目关联（M-04）。
- `DELETE /api/msa/:id` 拒绝已确认完成研究；新增作废接口（M-05）。
- `PATCH /api/gauges/:id` 编号唯一校验与清空校准到期日 warning（M-06）。
- `ensureMsaPlans` 研究设计解析失败写入备注（M-12）。
- 前端：计划“退回计划”按钮、研究“作废”按钮、维度变化清空确认（M-15）。

### 2.3 控制计划 / PFD / 数据哈希

- 建 CP 行校验样本容量 1–1000、频率 >0（C-05）。
- 工序新增/改号唯一性（P-03）；发布人取会话身份，撤回清空（P-05）。
- `DB.tx()` 检测 async 回调并回滚（S-16）。
- SPC 手工与 Excel 导入统一 `spcDatasetHash`（Q-07）；分选后数据阻止 PPAP 能力门（Q-08）。
- 前端修订监控后不再选中待审核项（Q-10）。

### 2.4 其他

- 特性关联判重覆盖 `status IS NULL`（D-06）。
- 交付物首次提交不强制变更原因（A-07）；导出走 blob 下载（A-14）；移除死按钮绑定并增加离开提醒（A-15）。
- ECR 影响抽屉展示结构化变更项与验证结论（E-04）。
