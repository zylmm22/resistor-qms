## 需要知道的边界

- **检具台账仍是全厂共享**：企业管理部维护一份，各项目按需引用。项目页看不到别项目的设备，但「本厂其他检具」里能看到编号与名称（台账属于基础数据，不含项目业务内容）。
- **账号级权限是“覆盖”不是“叠加”**：勾了自定义就完全按勾选执行，包括原本角色有的权限也会被去掉。这正是第 5 条要的能力（例如让某个人能批交付物但不能编辑）。
- **123456 是初始口令**：登录后仍会强制改密，改成 123456 会被拒绝（即使 `QMS_DEFAULT_PASSWORD` 被改成别的值，123456 仍在弱口令名单里）。若现场希望连改密也免掉，需要再确认。
- **账号管理与数据库备份仍只给系统管理员**：这两类接口直接管账号、读写备份文件，按 admin 角色校验，因此不在勾选清单里出现，避免勾了却不生效。
- **交付物影响分析**的上游/下游来自交付物目录里声明的 `up` / `down`，不是自由配置的关系；自定义交付物默认没有上下游。
