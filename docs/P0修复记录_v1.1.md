## 2. P0-2 项目隔离

**验收目标**：两项目并存时任一页面/接口不出现另一项目数据；`?p=` 越权返回 403。

| 编号 | 原问题 | 修复内容 | 主要位置 |
|---|---|---|---|
| S-02 | 多条聚合查询没有项目隔离 | `charCoverage` 的 links/cps/mons 三个子查询全部按 `project_id` 关联 `project_char`/`control_plan`；`mons` 只统计 `approval_status='已批准'`；总览审计流按 `project_id` 过滤；基线冻结的 CHAR/GAUGE 快照按项目引用过滤 | `lib/logic.js:372-391`、`lib/logic.js:414-415`、`lib/db.js:941-953/1032-1037` |
| S-05 | `?p=` 无成员校验 | 新增 `project_member` 表与 `canAccessProject()`；dispatcher 对显式 `?p=` 做存在性+成员校验，非成员返回 **403**；项目列表只返回当前账号可访问的项目；新增管理员维护成员接口 `GET/POST /api/admin/projects/:id/members` | `server.js:259-266`、`server.js:8276-8287`、`server.js:2034-2061` |
| B-05 | 基线快照的检具/特性未按项目过滤 | `CHAR` 只快照本项目 `project_char` 引用到的特性主数据；`GAUGE` 只快照本项目控制计划行引用到的检具（与 `projectGauges` 同口径）；`CHAR_LINK` 只快照两端属于本项目的关联 | `lib/db.js:941-953`、`lib/db.js:1032-1037` |
| D-07 | 穿透覆盖矩阵用全局数据 | 覆盖率数据源已按项目过滤，且 `mons` 要求监控项**已批准**；前端仍按“有/无”两档显示（多级覆盖状态未实现，见第 7 节） | `lib/logic.js:372-391`；`public/app.js` 覆盖率渲染未改 |

**兼容模式说明（重要）**：`canAccessProject()` 在项目**尚未配置任何成员**时对所有登录账号开放，这是为了不破坏现有演示库的过渡设计。**只要给项目配置了成员（哪怕一个），隔离立即对该项目生效**。生产部署后应立即为每个项目配置成员，否则 P0-2 只实现了“能配”，没有实现“默认收紧”。如需“默认拒绝”，把 `canAccessProject` 中 `if (!configured) return true;` 改为 `return false;` 即可，但需先完成成员配置。

**验证结果（已执行，详见验收报告）**：建 A/B 两项目，A 中建 CP/监控/特性；切到 B 后总览覆盖率、首页审计流、基线内容均不出现 A 的数据；非成员访问 `?p=A` → 403。

## 6. 新增/变更的数据结构与接口

### 6.1 数据库

| 对象 | 类型 | 用途 | 迁移方式 |
|---|---|---|---|
| `cp_revision` | 新表 | 控制计划版本快照（表头+行 JSON） | `CREATE TABLE IF NOT EXISTS` |
| `project_member` | 新表 | 项目成员，用于 `?p=` 隔离 | `CREATE TABLE IF NOT EXISTS` |
| `project_doc.lock_token` | 新列 | 交付物乐观锁 | `ensureColumn` |
| `ppap_submission.baseline_id` | 新列 | 提交记录绑定基线 | `ensureColumn` |
| `export_event.object_version` | 新列 | 导出对象版本 | `ensureColumn` |
| `fmea_decision.submitted_by` | 新列 | 判断“是否自批” | `ensureColumn` |
| `auth_user.must_change_password` | 新列 | 一次性口令改密标记 | `ensureColumn` |

老库升级：上述全部通过 `ensureColumn` / `CREATE TABLE IF NOT EXISTS` 自动完成，无需手工 SQL。`lock_token` 为空时首次保存不做冲突校验，保存后写入新 token。

### 6.2 接口

| 接口 | 说明 |
|---|---|
| `GET /api/cp/:id/revisions` | CP 版本列表 |
